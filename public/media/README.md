# Media — add your own photos & videos here

The site automatically uses any file you drop in these folders (then restart `npm run dev`, or run `npm run media`).
If a file is missing, the animated emblem is shown instead — nothing breaks.

Formats: .webp (best, smallest) .avif .jpg .png  |  video: .mp4 .webm
Images are auto-optimized by Next.js (resized + converted), so size is not a problem — but keep videos small (see below).

## Background video (home banner)
- media/bg.mp4        → muted looping background video (keep it under ~8 MB, 720p, 10–20 sec)
- media/bg.jpg        → poster image, also shown instead of the video in LITE mode

## Local trailer (optional — otherwise the official YouTube trailer is used)
- media/trailer.mp4
